## SYSTEM REQUIREMENTS

- Python 3.8 or above
- Internet connection (optional for libraries)


## INSTALL REQUIRED PACKAGES

Open Command Prompt / Terminal and run:
    pip install pandas matplotlib seaborn


## HOW TO RUN THE PROJECT

1. Place the CSV file inside the data folder.
2. Open terminal inside Task1_Data_Analysis folder.
3. Run the command:

**python analysis.py**


## OUTPUT

- Data analysis results printed in terminal.
- Graphs saved in output folder as PNG files.
