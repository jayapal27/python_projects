## TASK 3: MATRIX OPERATIONS TOOL PROJECT

    Provides a menu-driven tool that allows users to perform matrix operations such as addition, subtraction, multiplication, transpose, and determinant calculation.

## 📂 FOLDER STRUCTURE

Task3_Matrix_Operations_Tool/
│
├── matrix_operations.py   <--- Project main file
└── README.md


## SYSTEM REQUIREMENTS
    - Python 3.8 or above

## INSTALL REQUIRED PACKAGES
    Open Command Prompt / Terminal and run:
        pip install numpy


## HOW TO RUN THE PROJECT
    1. Open terminal inside Task3_Matrix_Operations_Tool folder.
    2. Run the command:
        **python matrix_operations.py**

## OUTPUT
    - Matrix operation results printed in terminal.
    - User can perform multiple operations in one execution.

## IMPORTANT NOTES FOR OTHER USERS
    - Enter matrix values carefully.
    - Dimension rules are validated automatically.
    - Program exits when user selects "no".
