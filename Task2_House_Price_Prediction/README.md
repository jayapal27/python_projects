## TASK 2: HOUSE PRICE PREDICTION PROJECT

    Predicts house prices using a Linear Regression model based on multiple features such as area, number of rooms, location, and other relevant factors.

## SYSTEM REQUIREMENTS
    - Python 3.8 or above
    - Internet connection (optional)

## INSTALL REQUIRED PACKAGES
    Open Command Prompt / Terminal and run:
        pip install pandas scikit-learn matplotlib joblib


## HOW TO RUN THE PROJECT
    1. Place Kaggle dataset inside data folder.
    2. Open terminal inside Task2_House_Price_Prediction folder.
    3. Run the command:

    **python house_price_prediction.py**


## OUTPUT
    - Model evaluation results saved in output folder.
    - Regression graph generated.
    - Trained model saved for future use.

## IMPORTANT NOTES FOR OTHER USERS
    - Dataset must include numerical and categorical features.
    - Categorical values are automatically encoded.
    - Do not rename dataset file unless code is updated.
