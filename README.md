## 📂 Projects Included

### 🔹 Task 1: Data Analysis and Visualization
- Performed data analysis on CSV datasets using Pandas
- Generated bar charts, scatter plots, and heatmaps using Matplotlib and Seaborn
- Extracted insights from structured data

**Technologies:** Python, Pandas, Matplotlib, Seaborn

---

### 🔹 Task 2: House Price Prediction (Linear Regression)
- Built a machine learning model to predict house prices
- Used multiple features such as area, rooms, location, and other factors
- Implemented Linear Regression with proper preprocessing and evaluation

**Technologies:** Python, Pandas, Scikit-learn, Matplotlib

---

### 🔹 Task 3: Matrix Operations Tool
- Developed a menu-driven matrix operations tool
- Supported addition, subtraction, multiplication, transpose, and determinant
- Implemented using NumPy

**Technologies:** Python, NumPy

---

### 🔹 Task 4: Speech to Image Generation (AI Project)
- Converted speech input into text using speech recognition
- Generated images from text using Stable Diffusion (Stability AI API)
- Demonstrated real-world AI API integration

**Technologies:** Python, SpeechRecognition, Stability AI API

---
### 🔹 Task 4: Voice-Activated Personal Assistant (AI Project)
- Developed a voice-controlled personal assistant using Python.
- Performs tasks such as:
    Checking weather information
    Reading news headlines
    Setting reminders
- Uses speech recognition for voice input and text-to-speech for spoken output

**Technologies:** Python, SpeechRecognition, pyttsx3 (Text-to-Speech), OpenWeather API, NewsAPI

---

### 🔹 Task 5: Sentiment Analysis Web Application (AI + NLP Project)
- Built a Flask-based web application for sentiment analysis
- Classifies user-entered text as:
    Positive
    Negative
    Neutral
- Displays polarity and subjectivity scores
- Designed with animated UI and background video

**Technologies:** Python, Flask, TextBlob, HTML, CSS
